What these checkboxes control

They control two separate sections on each user’s Jellyfin Home screen. They do not change who can access a library.

Show in My Media

Shows this library as a large tile in the My Media row—for example, a “Movies” tile that opens the full Movies library.

Show in Latest

Shows a separate row of recently added items from this library—for example, Latest Movies or Latest TV Shows.
